# 페이지 로딩과 캐시 원칙

새 페이지를 추가하거나 기존 페이지의 데이터 로딩 방식을 바꿀 때 다음 원칙을
기본값으로 사용합니다.

1. 제목, 설명, 가격, 기능 목록처럼 요청 결과와 무관한 UI는 즉시 표시합니다.
2. 사용자별 데이터가 들어가는 영역에만 실제 레이아웃과 크기가 같은 스켈레톤을
   표시합니다.
3. 다시 방문해도 안전한 조회 데이터는 `loadCachedRouteData`로 불러오고,
   `usePrimeRouteDataCache`로 최초 서버 데이터를 캐시에 등록합니다.
4. 데이터를 변경하는 action은 전역 캐시 버전을 갱신하거나 관련 캐시를 직접
   무효화합니다.
5. 전환 스켈레톤이 필요한 새 화면은 `RouteSkeletonVariant`에 전용 variant를
   추가하고, 실제 화면과 같은 최대 너비·여백·카드 구조를 사용합니다.
6. 빠르게 끝나는 이동에는 로딩 오버레이를 띄우지 않고, 지연되는 데이터 영역만
   스켈레톤으로 대체합니다.

결제처럼 민감한 화면은 캐시된 값을 화면 전환 속도 개선에만 사용하며, 실제 결제
승인과 권한 검증은 항상 서버에서 다시 수행합니다.
