# EOKKA 제품 변경 기록

완성했던 기능을 삭제하지 않고 운영 현실에 맞춰 전환한 이유와 구현 방식을
포트폴리오에서 설명할 수 있도록 남기는 문서입니다.

## 2026-10 무료 베타 운영 전환

### 기존 설계

- Toss Payments 정기결제 기반 EOKKA Pro
- Pro 목표 금액 최대 3개
- 거래일 자동 분석
- 상세 분석 기록 기간 제한 없이 보관
- 무료 사용자는 분석 결과만 확인하고 기록은 저장하지 않음

결제 UI, 구독 상태, 결제 내역, 자동 결제와 기존 Pro 권한 코드는 삭제하지 않고
향후 사업자·결제 심사가 준비됐을 때 다시 활성화할 수 있도록 보존합니다.
운영 중에는 `PAYMENTS_ENABLED=false`로 결제 진입 화면을 차단합니다.

### 베타 운영 설계

- 사용자가 Pro 미리보기를 선택하면 결제 없이 베타 기능을 체험
- 목표 금액 1개
- 자동 분석 미사용
- 수동 분석은 서버 영구 Rate Limit 적용
- 다시 열 수 있는 상세 분석 리포트는 최근 30개
- 장기 차트와 기간별 인사이트 데이터는 상세 리포트와 분리 보관

### 기록 보관 구조를 바꾼 이유

AI 답변, 종목별 재무정보, 장기 예상 차트가 포함된 전체 분석 JSON은 크기가 커서
무료 DB에서 무제한 보관하기 어렵습니다. 반면 자산 변화 차트와 연간 인사이트에는
매일의 핵심 수치만 필요합니다.

따라서 다음 두 저장소로 분리했습니다.

1. `analysis_snapshots`: 사용자가 다시 읽는 전체 분석 리포트, 최근 30개 유지
2. `analysis_history_points`: 차트와 기간 인사이트용 경량 수치, 장기 유지

경량 기록에서는 AI 대화, 긴 설명, 재무 원문, 매수 위치 상세값과 월별 장기 예상값을
제거합니다. 예상 차트는 연 단위 대표 지점만 남깁니다.

### 장기 데이터 압축 정책

- 최근 90일: 종가 날짜별 일간 포인트
- 91일~365일: ISO 주차별 마지막 포인트
- 1년 초과: 월별 마지막 포인트
- 같은 종가 날짜를 다시 분석하면 새 행을 만들지 않고 갱신

30개 초과에 따른 자동 정리는 전체 리포트만 삭제하며 장기 차트는 이어집니다.
사용자가 기록을 직접 삭제하거나 전체 초기화를 선택한 경우에는 사용자의 의도를
존중해 연결된 경량 기록도 함께 삭제합니다.
